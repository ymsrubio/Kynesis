## Agent skills

### Issue tracker

Issues live in GitHub Issues for `ymsrubio/Kynesis`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The seven default labels, unchanged: `bug`, `enhancement`, `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` at the root, and ADRs in `docs/adr/` once the first one is written. See `docs/agents/domain.md`.

### External peers

`host-only`: `code-review` and `jury` stay on the current host and call no external CLI. See `docs/agents/cross-model.json`.
